# Power BI Technical Notes

This folder contains supporting notes for the NordicFlow Power BI solution.

## Report Structure

The report includes:

- Executive Overview
- Inventory
- Rebalancing
- Suppliers
- Production
- BOM Risk
- Risk Analysis
- Management Actions

Supporting drill-through and tooltip pages provide additional detail where needed.

## Main Power BI Features

The solution uses:

- data modelling and relationships
- DAX measures
- slicers and filter context
- conditional formatting
- drill-through
- report-page tooltips
- bookmarks
- reset-filter controls
- page navigation
- cross-visual interaction

## Validation

Before publication, the report was reviewed for:

- KPI consistency
- slicer behaviour
- visual interactions
- drill-through
- tooltip behaviour
- navigation
- reset-filter behaviour
- labels and formatting

The final report version was used for the portfolio publication.
