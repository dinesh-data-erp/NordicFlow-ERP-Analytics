# NordicFlow Future Expansion Roadmap

## Phase I — Completed

NordicFlow Phase I is complete and available in this repository.

- Project 01 — Business & ERP Foundation
- Project 02 — ERP Data Model & Baseline
- Project 03 — Excel Data Engineering & Data Quality
- Project 04 — SQL Business Analysis
- Project 05 — Python ERP Analytics
- Project 06 — Power BI Executive Analytics & Decision Support

Phase I follows the same manufacturing ERP case from business requirements and data quality through analysis and management decision support.

---

## Phase II — Planned Development

Phase II will extend the existing NordicFlow environment. These projects are planned and have not yet been implemented.

### Project 07 — ERP Root-Cause & Process Analysis

Investigate operational problems across procurement, inventory and production at process level.

Main direction:

- shortage root-cause analysis
- supplier → material → production impact
- process bottlenecks
- exception analysis
- cross-functional ERP investigation

The aim is to move deeper from **what happened** toward **why it happened**.

---

### Project 08 — MRP & Inventory Planning Simulation

Extend NordicFlow into material planning and replenishment decisions.

Main direction:

- safety stock and reorder parameters
- material requirements
- shortage and excess simulation
- inventory planning scenarios
- inter-plant stock balancing
- MRP-style exception analysis

The focus will be how planning parameters affect material availability and working capital.

---

### Project 09 — Supplier & Procurement Improvement Analytics

Develop the supplier analysis into a more complete procurement decision case.

Main direction:

- supplier performance trends
- delivery reliability
- quality and rejection risk
- supplier segmentation
- purchasing exposure
- improvement priorities

This project will connect supplier performance with downstream inventory and production risk.

---

### Project 10 — ERP Migration, Data Quality & UAT Simulation

Simulate an ERP implementation or migration workstream using the NordicFlow data environment.

Main direction:

- source-to-target data mapping
- migration validation
- master-data quality controls
- reconciliation
- test scenarios
- UAT evidence
- defect and issue tracking

This phase will connect the analytics portfolio more directly with practical ERP implementation and data-migration work.

---

### Project 11 — Modern Analytics & AI-Assisted ERP Analysis

Extend the trusted ERP data foundation toward modern analytics and AI-assisted investigation.

Possible areas include:

- stronger semantic modelling
- reusable business measures
- Microsoft Fabric exploration
- natural-language questions
- AI-assisted KPI investigation
- support for analytical and DAX development
- explanation of unusual ERP signals

AI will be treated as an analytical assistant.

Reliable data, business definitions and human validation remain necessary.

---

### Project 12 — Integrated ERP Decision Intelligence

Bring the NordicFlow work together as an advanced management case.

The intended flow is:

**Business Signal → Investigation → Root Cause → Scenario → Recommendation → Human Decision / Action**

This stage may combine ERP process knowledge, data quality, planning, supplier analysis, semantic modelling, Power BI and AI-assisted analysis.

The goal is not more dashboards. It is a stronger connection between ERP information and business decisions.

---

## Development Direction

The longer-term NordicFlow direction can be summarised as:

**ERP Process → Reliable Data → Analysis → Semantic Model → BI → AI-Assisted Investigation → Human Decision / Action**

Projects will be added only when the underlying work has been completed. Empty project folders are intentionally not included in the repository.
